# market-scan

每個交易日自動抓取全球觀察池的 K 線，以程式計算技術指標與型態篩選，結果存到 `data/`,供 Claude 排程任務讀取分析。

## 執行時間(GitHub Actions)
- 週一至週五 台北時間 14:05(台股收盤後)
- 週六 台北時間 09:00(美股週五收盤後，週K 完整)
- 也可在 Actions 頁面按「Run workflow」手動執行

## 觀察池
- 台股：上市依當日成交值前 200 + 上櫃前 60(TWSE / TPEx OpenAPI),再依 20 日平均成交值取前 180
- 美股：標普 500 成分股依 20 日平均成交值取前 150,加主要 ETF
- 指數、期貨商品、外匯、加密貨幣：固定清單(見 `scan/universe.py`)

## 資料來源
Yahoo Finance(yfinance)。日K 為分割調整、未還原除權息。期貨／外匯／加密貨幣未收完的最後一根日K 會被移除不納入判斷。

## 篩選邏輯(`scan/screens.py`)
- 趨勢：Minervini 趨勢模板 7 項(K棒不足 200 根時用 20/60 日線簡化版);空頭結構與「剛轉空」
- 蓄勢型態：VCP(回檔逐次縮小、低點墊高、量縮)、Squeeze(布林 20,2 收進肯特納 20,1.5ATR)、均線糾結(5/10/20 日線差 3% 內)、量縮
- 觸發：放量突破前 20 日高(量 ≥ 50 日均量 1.5 倍)、Pocket Pivot、放量跌破
- 階段：蓄勢(距關鍵價 3% 內未突破)/ 剛發動(突破 3 根內、距突破點 5% 內)/ 已延伸
- 相對強度：63 日報酬相對基準(台股 vs 加權、美股 vs 標普)於同類中的百分位

## 輸出(`data/latest/`)
| 檔案 | 內容 |
|---|---|
| `meta.json` | 產生時間、各類別最後一根日K日期、失敗代號、移除的未完成 K 棒 |
| `candidates.md` / `candidates.json` | 前 15 名候選(每類最多 6 個)與完整判斷細節 |
| `screen_all.csv` | 所有分析標的的摘要 |
| `key_symbols.json` | 加權、標普、那斯達克、費半、小那、黃金、原油、台幣、比特幣最新收盤 |
| `bars/*_D.csv` `*_W.csv` `*_60m.csv` | 候選與關鍵指標的日K(260根)、週K(104根)、60分K(300根,台北時間)含指標 |

`data/history/日期/` 保存每日候選清單，供週回顧比對。

本專案為技術篩選工具，不構成投資建議。
